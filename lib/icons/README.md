# Silkscreen icons

`usb.svg` is the Google Material Icons "usb" glyph (filled style, 24 x 24), Apache
License 2.0 (`LICENSE-Apache-2.0.txt`), taken unchanged from the
`@material-design-icons/svg` package, version 0.14.13, by way of the MirrorLink workspace
(`../../MirrorLinkPCB/lib/icons/`, copied 2026-10-07). `lib/icons.py` converts it to
silkscreen polygons.

| Icon | Used for |
|---|---|
| `usb` | the Teensy's USB end (its orientation), on both faces |
